시장조사 핵심 요약

이번 시즌 헤드웨어는 방한 기능 외에 실루엣·소재·스타일링 표현에 따라 차별화된 상품군이 형성되는 양상을 보인다. 특히 일부 국내 유통 상품에서는 패딩 바라클라바와 퍼·플리스 트루퍼의 카테고리 상위 노출 기록을 확인할 수 있다. 단, 이 사례를 시장 전체 성장률로 확대 해석하지 않는다.

확인된 관찰

무신사 일부 개별 상품의 카테고리 랭킹 기록, 29CM·크림 개별 상품 사례, W컨셉 관련 외부 과거 가격 기록.

MD 기획 가설

두 가지 방식 바라클라바 / 소재 차별화 트루퍼 / 미니멀 구조적 햇의 단계별 소량 테스트.

추가 검증 필요

수치 미확보

국내 헤드웨어 시장규모, 플랫폼별 판매량·거래액, 전년 대비 증가율, 정확한 점유율.

자료 검증 기준

① 관찰 데이터

실제 페이지/정보 연동 서비스에 존재하는 상품·가격·후기 수 등의 기록. 가격 관찰일과 출처를 별도 표시.

② 과거 기록

검색 스냅샷·제3자 기록은 표본으로만 보존하고 실시간 판매가나 전년 비교 수치로 활용하지 않음.

③ MD 분석 및 전략

우선순위·상품기회·타깃 가격대는 검증된 사실이 아닌 제안으로 라벨링.

④ 자동 수집 원칙

공식 정보 연동 서비스 또는 허용된 공급 데이터만 사용. 수집 실패 시 값을 추정해 채우지 않고 이전 기록을 유지하고 오류를 표시.

설정 전

AI 토큰 없는 자동 갱신 구조

사이트는 생성형 AI를 호출하지 않고 정해진 주기에 데이터 파일을 갱신하는 방식으로 설계되어 있습니다. 공식 정보 연동 서비스와 인증된 제공 피드를 읽어서 docs/data/market.json 및 관찰 이력에 기록하고 웹사이트가 새 파일을 가져오도록 구성했습니다.

자동화 주기

깃허브 자동 실행 기능에 매일 09:17 한국 시간 갱신 일정 설정. 실제 작동은 저장소에 업로드하고 자동 실행 기능을 활성화한 뒤부터 시작됩니다.

현재 가능한 연결

네이버 공식 쇼핑 검색 API(정보 연동 서비스) (클라이언트 키 필요). 무신사, W컨셉, 29CM, 크림은 허용된 승인된 데이터 제공 경로를 연결해야 자동 가격 수집 가능.

AI 토큰 사용

일반 데이터 업데이트에 AI 토큰 0개. 다만 외부 API(정보 연동 서비스)·깃허브 자동 실행 기능 운영에는 서비스 제공자의 인증, 호출 제한 및 비용 조건이 적용될 수 있습니다.

사이트 온라인 공개 설정

1단계 — 깃허브 저장소 만들기

첨부한 압축파일(ZIP)을 새로운 깃허브 저장소에 올립니다. docs/ 폴더가 사이트이고 .github/workflows/가 자동갱신 작업입니다.

2단계 — 웹사이트 공개 설정

설정(Settings) → 페이지(Pages) → 브랜치로 배포(Deploy from a branch) → main / /docs를 선택합니다.

3단계 — 네이버 상품정보 연결

깃허브 저장소 비밀 변수(Secrets)에 NAVER_CLIENT_ID, NAVER_CLIENT_SECRET을 설정하고 자동 실행 기능을 활성화합니다.

4단계 — 나머지 플랫폼 연동

나머지 4개 플랫폼은 공식 제공 피드/승인된 데이터 전달 방식이 확보되면 feeds/ JSON에 연결해 주기 갱신합니다.

5단계 — 자동 갱신 확인

자동 실행(Actions) 메뉴에서 실행 로그를 확인하고, 이 화면의 최신 갱신일과 수집 상태를 점검합니다.
