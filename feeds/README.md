# 승인된 외부 플랫폼 피드

무신사, W컨셉, 29CM, 크림은 **공식 API 또는 플랫폼/브랜드에서 적법하게 제공받은 데이터**만 연결하세요. 브라우저 페이지 무단 크롤링, 차단 우회, 로그인 정보 수집은 이 프로젝트에 포함되지 않습니다.

실제 수집 데이터를 확보하면 예를 들어 `feeds/wconcept.json` 파일을 다음 형식으로 넣을 수 있습니다.

```json
{
  "platform": "W컨셉",
  "provider": "플랫폼에서 제공한 상품 데이터",
  "collectedAt": "2026-10-14",
  "products": [
    {
      "id": "상품번호-1234",
      "name": "실제 판매 상품명",
      "brand": "실제 브랜드명",
      "category": "바라클라바",
      "material": "패딩",
      "price": 49000,
      "originalPrice": 59000,
      "coupon": "상품가 기준 / 쿠폰 제외",
      "url": "https://www.wconcept.co.kr/...",
      "image": "https://..."
    }
  ]
}
```

이 문서는 포맷 안내이며 샘플값을 실제 데이터로 넣으면 안 됩니다. 수집 날짜를 수정하지 않고 파일을 반복 실행할 경우, 새 날짜의 관찰값이 생성되지 않습니다. 5개 채널의 진짜 일일 자동 업데이트에는 채널별 제공 데이터의 정기 공급이 필요합니다.
