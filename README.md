# 워크룸 — 통합 업무공간 한국어 시제품

**시장조사 + 프로젝트 + 업무 + 일정 + 상품 + 프로모션 + 콘텐츠 + 자료 관리**를 한 사이트로 묶은 기본틀입니다.

- 참고: [OpenProject 저장소](https://github.com/opf/openproject) 및 [기능 소개](https://www.openproject.org/). OpenProject는 프로젝트/포트폴리오, 업무, 간트, 칸반, 회의록, 협업 기능을 지원합니다.
- **중요:** OpenProject의 소스코드나 UI 자료를 복사·포함하지 않았습니다. 원본 저장소의 라이선스는 GPLv3입니다. 이 프로젝트는 별도로 작성한 HTML/CSS/JavaScript로 구성돼 있습니다.
- 화면은 모두 국문. OpenProject와 똑같이 동작하는 복제품이 아니라 MD 업무에 맞춘 **확장 가능한 시제품**입니다.

## 파일 열기

1. 압축파일을 풀고 `docs/index.html`을 브라우저에서 엽니다.
2. **왼쪽 메뉴 → 시장조사·경쟁분석**을 클릭하면 이전에 만든 5개 플랫폼 헤드웨어 분석 화면이 나옵니다.
3. 프로젝트 / 할 일 / 상품 / 프로모션 / 콘텐츠 / 자료를 직접 추가·수정·삭제할 수 있습니다.
4. 업무 카드는 상태별로 드래그할 수 있고 캘린더에서 일정이 보입니다.
5. `데이터·설정`에서 업무 기록을 JSON 파일로 백업·복원할 수 있습니다.

**주의:** `file://`로 실행하면 일부 브라우저에서 보안 제한으로 저장 기능이나 시장조사 외부 데이터 갱신이 동작하지 않을 수 있습니다. 안정적으로 이용하려면 정적 웹서버나 GitHub Pages로 열어주세요.

## 배포: GitHub Pages

1. 본 프로젝트 파일을 **사용자 소유** 새 GitHub 저장소에 업로드합니다. `opf/openproject`는 참고자료일 뿐 배포 저장소가 아닙니다.
2. GitHub 저장소 `설정 → 페이지 → 브랜치에서 배포`로 들어갑니다.
3. `main` / `/docs`를 선택합니다.
4. 배포가 완료되면 `https://<사용자아이디>.github.io/<저장소이름>/`으로 엽니다.
5. **GitHub Pages는 정적 사이트**로, 사이트의 업무 데이터는 브라우저별로 분리되어 저장됩니다. 팀원 공유·기기간 동기화·로그인 기능은 제공하지 않습니다.

## 현재 구현한 기능

| 메뉴 | 현재 가능한 것 | 추후 연결 |
|---|---|---|
| 전체 현황 | 진행 프로젝트/업무/행사/콘텐츠 수치, 일정, 바로가기 | 실제 팀별 지표 |
| 프로젝트 관리 | 생성·수정·삭제, 연결 업무 진행률 | 하위 작업, 의존성, 간트, 권한 |
| 할 일·칸반 | 업무 등록, 수정, 상태 드래그, 목록, 우선순위 | 알림, 댓글, 첨부파일 |
| 일정 캘린더 | 업무·콘텐츠·프로모션 날짜 통합 | 외부 달력 동기화 |
| 시장조사 | 기존 5개 플랫폼 상품/가격/그래프/출처 화면 보존 | API/허용된 수집 피드 |
| 상품·SKU 관리 | 상품명, SKU, 가격, 상태, 플랫폼 | PLM/PIM, 재고, 실판매 연동 |
| 프로모션 관리 | 행사 기간, 채널, 승인 상태 | 쿠폰·가격 검증 자동화 |
| 콘텐츠 관리 | 채널, 게시 예정일, 상태 | 콘텐츠 성과 자동 수집 |
| 자료·회의록 | 문서 저장, 분류, 편집 | 검색 인덱스, 협업 댓글 |
| 데이터·설정 | JSON 백업/복원, 시연 데이터 초기화 | 팀 DB와 권한 |

## 데이터 안전성 / 수집 정책

- 업무 데이터는 현재 사용 중인 **브라우저의 localStorage**에 보관됩니다. 브라우저 데이터 삭제·시크릿 모드·다른 컴퓨터에서는 손실되거나 동기화되지 않습니다. `데이터·설정 → 데이터 백업`을 사용하세요.
- 시연용 콘텐츠는 모두 가상 예시입니다. 개인정보·계약서·기밀 회사 자료를 공개 Pages 저장소에 넣지 마세요.
- 시장조사 데이터는 기존 자료를 보존했습니다. 관찰가격은 실시간 실결제가가 아니며 근거없는 시장규모·판매량을 생성하지 않습니다.
- 외부 플랫폼 공식 API 또는 허용된 피드만 연결합니다. 서비스 약관에 위배되는 크롤링은 기본 활성화하지 않습니다.
- 기존 자동 수집 예시 워크플로는 `.github/workflows/update-market.yml.disabled`로 비활성화 상태로 포함했습니다. 각 플랫폼 데이터 권한/키가 준비되면 승인 후 별도로 활성화하세요. 기본 UI 자체는 AI 토큰을 사용하지 않습니다.

## 프로젝트 구성

```
docs/
  index.html             # 새로운 통합 업무공간 진입점
  workspace.css          # 통합 업무공간 UI
  workspace.js           # 메뉴 / CRUD / 칸반 / 캘린더 / 백업
  market.html            # 기존 5개 플랫폼 시장조사 (원래 UI/기능 보존)
  data/market.json       # 기존 시장조사 데이터
  .nojekyll
scripts/update_data.py    # 기존 허용된 데이터 수집 스크립트 (연동 필요)
feeds/                   # 승인된 플랫폼 피드 자리
.github/workflows/update-market.yml.disabled # 자동 수집 비활성화 샘플
설계문서.md
코덱스_개발요청서.md
```
